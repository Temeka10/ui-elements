Демонстрація UI Елементів

1. Radiobutton

Призначення: Радіокнопка. Використовується, коли користувачеві потрібно вибрати строго один варіант із запропонованого списку взаємовиключних опцій.

2. Checkbox

Призначення: Прапорець. Дозволяє вибрати декілька, один або жодного варіанту з множини. Використовується для налаштувань, згод та множинного вибору.

3. Text input

Призначення: Текстове поле. Дозволяє користувачеві вводити однорядковий текст (наприклад, логін, пошуковий запит, ім'я).

4. Tabs
Вміст першої вкладки.
Вміст другої вкладки.

Призначення: Вкладки. Розділяють великий обсяг інформації на логічні блоки, дозволяючи перемикатися між ними без перезавантаження сторінки.

5. Button

Призначення: Кнопка. Інтерактивний елемент, що ініціює певну дію при натисканні (збереження даних, відправлення форми, закриття вікна).

6. Text label

Призначення: Текстова мітка. Описує поле введення або інший елемент керування, пояснюючи користувачеві, яку інформацію необхідно ввести.

7. Link
Перейти на Вікіпедію (Посилання)

Призначення: Гіперпосилання. Використовується для навігації між вебсторінками, переходу на інші сайти або до певних частин поточного документа.

8. Tooltip

Призначення: Спливаюча підказка. Надає додаткову інформацію або пояснення, коли користувач наводить курсор на елемент, не захаращуючи інтерфейс.

9. Dropdown list

Призначення: Випадний список. Економить місце на екрані і дозволяє вибрати один пункт із великого масиву прихованих варіантів.
